
# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are stored in the browser using localStorage so that they remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work or Study
- Display the date and time each note was created
- Delete individual notes
- Delete all notes with confirmation
- Validate empty notes
- Limit notes to 200 characters
- Search notes without case sensitivity
- Display the correct number of notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive layout for smaller screens

## How to run the project locally

1. Clone or download the project.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.
